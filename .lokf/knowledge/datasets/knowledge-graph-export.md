# Overview

Generated by the CLI: `./ai graph --export --byod` produces the merged knowledge graph as `graph/ai-risk-ontology.yaml` (~45k lines), and `./ai graph cypher --export --byod` produces `graph/cypher/ai-risk-ontology.cypher` via `graph/cypher/export.py` (cymple QueryBuilder over the linkml instance data). The two differ in scope: the YAML export honours `--byod`, but the Cypher handler runs `export.py`, which loads the packaged ai-atlas-nexus data only, so the Cypher distribution never contains BYOD files. The Cypher distribution is what the [Neo4j graph database service](../services/graph-db.md) imports.

Both distributions are regenerable artifacts - the sources of truth are the upstream ai-atlas-nexus package data and, for the YAML export, the BYOD files under `byo/data/`.
